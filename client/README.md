# 💻 SmartRecruit AI - Client Frontend

Giao diện người dùng nền tảng tuyển dụng thông minh **SmartRecruit AI**, được xây dựng bằng React 18, Vite và bộ CSS Design System Doanh nghiệp hiện đại.

Tài liệu chi tiết toàn bộ dự án (bao gồm Backend, AI Gemini, 12 chức năng mục 2.3, danh sách API, hướng dẫn chạy và cấu hình tài khoản):
👉 Xem file [README.md chính ở thư mục gốc](../README.md).

---

## 🚀 Khởi Chạy Frontend Nhanh

```bash
# Cài đặt dependencies
npm install

# Khởi chạy Vite Dev Server
npm run dev

# Build sản phẩm hoàn chỉnh
npm run build
```

Mặc định giao diện chạy tại: `http://localhost:5173`
Kết nối với Backend tại: `http://localhost:5000` (xem `src/services/api.js`).
